3. HERRAMIENTAS Y SCRIPTS CREADOS
Todos los scripts están en C:\Users\david\traductor_v3\. Son archivos .mjs (Node.js).

spc_extract.mjs: Extrae los subarchivos .stx de un archivo .spc.

Uso: node spc_extract.mjs <archivo.spc> <carpeta_salida>

spc_repack.mjs: Empaqueta una carpeta de .stx en un .spc (con compresión LZ byte-perfect).

Uso: node spc_repack.mjs <carpeta_stx> <archivo_spc_salida>

stx_extract.mjs: Convierte un .stx a un .txt editable con marcadores #####.

Uso: node stx_extract.mjs <carpeta_stx> <carpeta_txt>

stx_repack.mjs: Convierte una carpeta de .txt (con marcadores) de vuelta a .stx.

Uso: node stx_repack.mjs <carpeta_txt> <carpeta_stx_salida>

traductor_stx.mjs: Traduce los .txt usando la API de DeepSeek. Usa glosario.txt y personajes.txt. Aplica reglas de género gramatical. Prohíbe tildes, ñ, ¿¡, comillas tipográficas, etc.

Uso: node traductor_stx.mjs <carpeta_txt_entrada> <carpeta_txt_salida> <ruta_glosario>

pipeline.mjs: Automatiza todo el proceso para una carpeta de .spc (extrae, convierte, traduce, reempaqueta, copia al mod).

Uso: node pipeline.mjs <carpeta_spc_originales> <carpeta_mod_destino>

Procesa solo archivos que contengan _text_ en el nombre.

limpiar_acentos.mjs: Elimina tildes, ñ, ¿¡, etc. de una carpeta de .txt.

Uso: node limpiar_acentos.mjs <carpeta_txt_entrada> <carpeta_txt_salida>

limpiar_mod.mjs: Aplica limpiar_acentos a todos los .spc de una carpeta del mod y los reemplaza.

Uso: node limpiar_mod.mjs <carpeta_mod>

spc_info.mjs: Muestra la estructura interna de un .spc.

Uso: node spc_info.mjs <archivo.spc>

verificar.mjs: Compara marcadores y etiquetas entre original y traducido.

Uso: node verificar.mjs <carpeta_original> <carpeta_traducida>

7. REGLAS DE TRADUCCIÓN (en traductor_stx.mjs)
No tildes (a, e, i, o, u sin acento).

No ñ (usar n).

No ¿ ni ¡ (solo signos de cierre).

Comillas rectas ("), no tipográficas.

Guiones normales (-), no largos.

Género gramatical correcto según personajes.txt.

No modificar etiquetas <CLT=...> ni marcadores ##### NNNN.
